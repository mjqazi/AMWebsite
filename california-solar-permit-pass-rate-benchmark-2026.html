Prepare an industrial PV drawing package for review.

Use a consistent input and comment register for each project. This is a planning checklist, not a measured California permit pass-rate benchmark.

Check the starting information.

Confirm the current site information, equipment selections, electrical connection point and required drawing list. Identify the utility and reviewing authority’s project-specific submission requirements with the responsible designer.

Make review comments usable.

  1. Record the drawing and revision each comment refers to.
  2. Distinguish missing information from a design change.
  3. Name the person responsible for the response.
  4. Carry agreed changes through connected schedules and diagrams.
  5. Check the issue register before resubmitting the package.

Avoid using an acceptance percentage without a defined dataset, review period and treatment of resubmissions. This page does not publish such a dataset.

Keep the submission scope explicit.

Producing drawings, completing a submission and obtaining approval are different responsibilities. Agree who supplies the calculations, who signs where required and who handles reviewer queries.
